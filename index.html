Note: This is a Django application. Please run it locally using:
python manage.py runserver
Player Registration

Tournament Management

Create and manage netball tournaments

Team Formation

Assign players to teams efficiently

Getting Started

  1. Install dependencies: pip install -r requirements.txt
  2. Run migrations: python manage.py migrate
  3. Create superuser: python manage.py createsuperuser (default: admin/admin123)
  4. Start server: python manage.py runserver
  5. Visit http://localhost:8000 for player interface
  6. Visit http://localhost:8000/admin for admin dashboard
